Lời nói đầu

Khách hàng liên hệ qua nhiều kênh; doanh nghiệp cần một điểm điều phối để thống nhất dữ liệu, phân quyền và theo dõi phục vụ. Khi mỗi bộ phận dùng công cụ riêng, vận hành dễ chậm, khó kiểm soát an toàn và thiếu trải nghiệm chung cho đội ngũ chăm sóc khách hàng cùng quản trị.

**CGV Omnichannel** là hệ thống phần mềm đa kênh dạng cổng quản trị trên web, gom báo cáo vận hành, quản lý khách hàng và đơn vị, nhân sự và lịch, thanh toán — cùng kênh trò chuyện hỗ trợ — trong một giao diện, nhằm thống nhất vận hành chăm sóc khách hàng và quản trị thay cho nhiều công cụ rời rạc.

Tài liệu giới thiệu phạm vi giải pháp: tổng quan, kiến trúc và chức năng chính, nguyên tắc vận hành an toàn, hướng triển khai và mở rộng — làm căn cứ tham khảo cho đội triển khai và vận hành.

Danh mục từ viết tắt và thuật ngữ

| Từ viết tắt | Tên đầy đủ                        | Mô tả chi tiết                                                                                                    |
| ----------- | --------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| API         | Application Programming Interface | Giao diện lập trình để client và server trao đổi dữ liệu theo chuẩn định nghĩa                                    |
| RBAC        | Role-Based Access Control         | Phân quyền dựa trên vai trò và quyền gán cho từng đối tượng người dùng                                            |
| JWT         | JSON Web Token                    | Định dạng token xác thực (thường Bearer) mang thông tin phiên và ký điện tử                                       |
| REST        | Representational State Transfer   | Phong cách triển khai API HTTP theo tài nguyên và phương thức chuẩn                                               |
| SSR         | Server-Side Rendering             | Kết xuất giao diện phía máy chủ (Next.js hỗ trợ SSR/SSG kết hợp App Router)                                       |
| SPA         | Single Page Application           | Mô hình ứng dụng một trang, điều hướng mượt trong trình duyệt                                                     |
| CSKH        | Chăm sóc khách hàng               | Hoạt động hỗ trợ, tiếp nhận và phản hồi nhu cầu khách hàng đa kênh                                                |
| CRM         | Customer Relationship Management  | Quản trị và theo dõi quan hệ khách hàng (ở phạm vi gói nhẹ/tích hợp trong nền tảng)                               |
| WS          | WebSocket                         | Kênh giao tiếp song công thời gian thực; phía client được triển khai qua Socket.IO và xác thực token khi khởi tạo |
